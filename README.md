# ProjectsCraft

Real projects built entirely with the **[ArtCraft](https://github.com/storytold)**
suite — the clean-room, open-source, Rust-native reimplementations of
the industry's creative, office and technical tools — exercising the
whole pipeline end to end through the apps' CLIs.

ProjectsCraft is a companion effort, not the suite itself: the Craft
apps are developed by [storytold](https://github.com/storytold).

Read **[vision.md](vision.md)** for the full vision.
