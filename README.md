# ProjectsCraft

The umbrella for the Craft app suite — clean-room, open-source,
Rust-native reimplementations of the industry's creative, office and
technical tools — and the playground campaigns that exercise them
end to end.

Read **[vision.md](vision.md)** for the full vision: the suite, the
shared principles (clean-room, Rust only, never crash, everything is a
command), and the LUMA AURA launch campaign that proved the whole
pipeline from the CLIs.
