# ProjectCraft

A complete, open-source project-management suite — the clean-room,
Rust-native alternative to **Jira, monday.com, Asana, ClickUp and
Microsoft Project** in a single tool.

One engine, every lens: issues, sprints and boards; tables, calendars
and dashboards; Gantt, critical path, baselines and resource levelling —
all views over the same document, local-first and agent-drivable.

Built the [ArtCraft](https://github.com/storytold) way — the suite's
conventions, not the suite's code.

Read **[vision.md](vision.md)** for the full vision.
